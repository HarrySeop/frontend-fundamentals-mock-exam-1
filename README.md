## 💡 UX 개선 제안

### 현재 한계점

개발 과정에서 사용자 경험 측면에서 아쉬웠던 부분들이 있습니다:

#### 1. 저축기간 "전체" 옵션 부재

현재 저축기간 선택이 특정 값(6개월, 12개월 등)으로 제한되어 있어, 모든 저축기간의 상품을 한눈에 볼 수 없습니다. 사용자가 다양한 기간의 상품을 비교하려면 매번 기간을 변경해가며 확인해야 하는 불편함이 있습니다.

#### 2. 조건 외 상품 조회 불가

상품 목록이 입력 조건(월납입액, 저축기간)에 맞춰 필터링되기 때문에, 조건에 맞지 않는 상품이나 전체 상품 목록을 볼 수 없습니다. 이로 인해:

- 조건을 조금만 변경하면 어떤 상품이 있는지 미리 파악하기 어려움
- 전체 상품 풀(pool)에 대한 이해도가 떨어짐
- 상품 탐색의 유연성이 제한됨

### 개선 방향 제안

위 문제들을 해결하려면 **현재의 단일 페이지 탭 구조를 변경**하는 것이 필요합니다:

#### 개선안: 2단계 페이지 플로우

1. **1단계 페이지 (상품 탐색)**:
   - 저축기간에 "전체" 옵션 추가
   - 필터 조건 입력 (선택사항)
   - 전체 상품 목록 표시 (필터링된 상품은 하이라이트)
   - 상품 선택 후 "계산하기" 버튼으로 다음 페이지 이동

2. **2단계 페이지 (계산 결과)**:
   - 선택한 상품과 입력 조건 기반 계산 결과 표시
   - 추천 상품 목록
   - "다시 선택하기" 버튼으로 이전 페이지 복귀

3. **조건 안내 방식**:
   - 필터 조건 미입력 시: 모달 또는 토스트 UI로 "조건을 입력하면 적합한 상품을 추천해드려요" 안내
   - 조건에 맞지 않는 상품 선택 시: 토스트로 "이 상품은 입력하신 조건에 맞지 않아요" 경고

#### 기대 효과

- ✅ 전체 상품 탐색 가능
- ✅ 조건 입력이 선택사항이 되어 사용자 자유도 증가
- ✅ 필터링과 계산이 명확하게 분리되어 직관성 향상
- ✅ 모달/토스트로 부드러운 사용자 가이드 제공
